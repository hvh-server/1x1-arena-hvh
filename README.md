# 1x1 HVH и Arena — дуэли, хвх арена, 1v1

Страница под **1x1 hvh**, **1v1 hvh**, **hvh csgo 1x1**, **hvh arena**, **csgo hvh arena**, **хвх арена**, **хвх 1х1**, **хвх дуэли**. Короткий формат, плотный замес, меньше «беготни по карте ради ничего».

## Как зайти

В консоли CS:GO:

```
connect hvh.wok.pink:1488
```

или напрямую по IP:

```
connect 46.174.55.52:1488
```

Актуальный IP, розыгрыши и новости сервера — в группе: [https://vk.com/wokhvh](https://vk.com/wokhvh)

## 1x1 и arena рядом

В поиске **1x1 hvh** и **hvh arena** часто идут рука об руку. Кто-то хочет чистый duel, кто-то arena-слой. На практике людям нужен сервер, где такой вайб живёт, и чат/группа, где скажут расписание. Connect — ниже по смыслу всегда один: **WOK HVH**.

## Почему не отдельный IP на каждую дуэль

Потому что это хаос для игроков. Один сервер, понятный адрес, новости в одном месте. Если когда-нибудь появится особый ивент — его объявят в **https://vk.com/wokhvh**, а не спрячут в пятом README.

## Анти-каннибализм
